# Tahmid ♥ Tonni — 10.10.2026

Black + Pink + Glow romantic proposal website.

## Files
- `index.html` — main site (hero countdown, journey, love letter, music, gallery, proposal teaser)
- `proposal.html` — date-locked proposal page (unlocks 10 Oct 2026)
- `styles.css` — black + pink neon glow theme
- `main.js` — countdown, particles, timeline, letter typing, gallery, confetti

## Customize (5 min)
1. **Letter:** `main.js` → `LETTER_TEXT` edit করো
2. **Timeline:** `main.js` → `TIMELINE` array এ নিজেদের স্মৃতি বসাও
3. **Song:** `index.html` → Spotify iframe `src` বদলে নিজেদের গানের embed link দাও
   (Spotify → Share → Embed track)
4. **Photos:** `images/` ফোল্ডার বানিয়ে ছবি রাখো, `main.js` → `GALLERY` তে `{ src:'images/tonni1.jpg', caption:'...', date:'...' }` যোগ করো
5. **Propose date:** `main.js` + `proposal.html` এ `PROPOSE_DATE` / `DATE` বদলাও (যদি দরকার হয়)

## Run locally
Double-click `index.html` — অথবা VS Code Live Server.
